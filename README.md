# 🎬 Full-Stack E-Commerce Movie Portal & Admin CRM
A production-ready e-commerce movie store and management portal built using Next.js 16, React 19, and Supabase.
### 🌐 Live Links
* **Production Store:** [https://ecommerce-movie-portal.vercel.app/movies](https://ecommerce-movie-portal.vercel.app/movies)
* **Interactive API Playground:** [https://ecommerce-movie-portal.vercel.app/api-doc](https://ecommerce-movie-portal.vercel.app/api-doc)
### 🚀 Key Features
* **Modern Stack:** Next.js 16 App Router, React 19 Server Actions, Tailwind CSS, Radix UI.
* **Database & ORM:** Supabase PostgreSQL cloud database, Prisma ORM, transaction pooling.
* **Full-Scale CRM Dashboard:** Track Gross Sales, average transaction value, and real-time revenue trends. Manage and moderate customer status (ban/unban controls) and inspect customer LTV.
* **Secure Auth:** Better Auth integration with automated SMTP verification emails.
* **Stripe Integration:** Dynamic billing flows with inventory lock validations during processing.
